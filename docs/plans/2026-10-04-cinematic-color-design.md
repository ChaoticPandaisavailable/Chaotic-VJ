# 电影意境调色

保留所有形态、前三套表达和按需过渡。依据用户六张绘画照片的墨色、清白、局部浓色关系调整色彩，不采纳室内照明的黄偏。用户提供七种意境，直接在现有颜色下拉框中加入七个可调方案。避免新增常驻面板。

方案比较：只改全局饱和度无法建立主次；导入摄影 LUT 与本项目的单通道生成场不匹配；采用手工编排的明暗色彩角色、Oklab 插值、独立亮部弥散。自由 XY 继续覆盖全色相，七种意境的 XY 限定在各自情绪范围，自动变色缓慢往返，保留 MIDI 和自定义 HEX。

五个角色为深底、暗部、主色、浅色点缀、白色。暮色以绛紫、烟粉、桃橘相接；草甸以墨绿、翡翠、嫩苔及轻微花色相接；沉金只在亮部浓金；风暴以夜蓝与青蓝相接；苍松降低色度、增加净白；熔流用焦黑、深红、金橙；棱镜独立使用连续全谱曲线。保证明度有序，按色弱近似模型检查角色分离。

在低分辨率 GPU 纹理提取亮部并生成近、远两级光晕，原始形态仍以原精度绘制。远层轻微呼吸、方向性散射；避免全图模糊与全图暖染。最终高光使用柔和肩部曲线，保留色相，黑位不泛灰。沿用微光滑杆控制强度，置零关闭弥散。

备份：`backups/2026-10-04-before-cinematic-color-1b8480b5`。包含 103 个文件的校验记录、源码、构建产物、锁文件及当前运行配置/图片。依赖目录、私有管理密钥不复制。

资料：
- [Oklab 原作者说明](https://bottosson.github.io/posts/oklab/)：分离感知明度和色度、平滑插值，沿用项目已有转换。
- [ARRI Color FAQ](https://www.arri.com/en/learn-help/learn-help-camera-system/image-science/color-faq)：色彩转换与 look 是不同处理，本项目不直接套相机 LogC LUT。
- [Kodak / Zola 摄影访谈](https://www.kodak.com/en/motion/blog-post/zola/)：按情绪阶段控制色彩与反差，支持将七种意境分成可选方案。
- [ASC / Hollywood Babylon](https://theasc.com/article/hollywood-babylon/)：亮部触发自然光晕的制作参考。这里是生成艺术近似，不宣称模拟某种真实胶片或 HDR 输出。

验证：色板全域与边界连续性、色弱近似明暗排序、预设迁移/MIDI/冻结/输出同步；构建及完整回归。浏览器用相同画质实看七套方案、变化和切换，检查低分辨率光晕开销。完成后记录结果。

## 2026-10-04 后续修订：留白与实时交接

用户的新反馈推翻了“所有方案都以黑底、白色高光结束”的假设。此次备份位于 `backups/2026-10-04-before-air-and-clean-transitions`。雪松改为雪白负空间、淡雾绿、中段松绿、深墨绿；暮色以浅桃色留白、粉橘到深紫构成；棱镜以珍珠浅底、青蓝紫为深部，避免在低亮度分配黄橙而变褐。草甸为林绿、嫩叶与浅暖点染；熔金、风暴、熔流分别保留深褐金、夜蓝青、炭黑红橙。
