# 宇宙光幕与演出快捷位

当前版本先同步到 GitHub main，基线提交 1065d71。保留用户喜欢的熔流星云、原版深空旋臂与全部九种现有视觉；旧效果不重新进入菜单。

## 参考与取舍

观察 https://ahlookah.com/ 及其 interface、patterns、slots 文档，并实际打开 Aurora Veil、Tidal Glass、Membrane Modes：效果按主题分组、参数随选择更新，常用效果通过数字快捷位调用，Shift 预备下一幕。Aurora Veil 的光幕和 Tidal Glass 的液态反光提供了方向；本项目的潮汐效果选择铺满空间的交叠波面，而非复制参考站的双团玻璃体。采用概念和操作顺序，独立编写本项目着色器，不复制参考站代码或素材。

三个可能方向：扩充大量效果会使选择重新杂乱；完整复制双窗口 CUE 工作台会挤压主画面并增加渲染负担；本轮选择两种区别明确的视觉，加上紧凑的演出快捷位与搜索。继续沿用现有输出窗口和 A/B。

## 实现

- 极光风幕：分层弯曲光帘、稀疏星点与长纤维。Bass 积分推动内部光流，实测 Kick 的局部光浪沿光幕横向传播，高频提高少量细丝亮度。
- 潮汐光池：交叠的波面、流动焦散与留白暗隙。Bass 持续输送波面，Kick 产生空间传播的涟漪，高频点亮波峰。没有声音时没有伪造鼓点；自主缓动与音乐作用分开。
- 新增稳定 style 19、20，原 scene/MIDI 索引 0–18 不变。旧 MilkDrop 识别范围维持 11–18。
- 六个可编排快捷位持久化在本浏览器。按 1–6 切换，Shift+数字或 Shift+点击视觉排入下一幕，Enter 切入、Escape 取消。下一幕是待切换列表，不声称为离屏预览或已完成 GPU 预热；沿用引擎原有的平滑切换与异步准备。
- 搜索覆盖名称、描述和分类；无结果可清空。快捷键在输入、选择、编辑文本或组合输入时不接管。
- 当前配色、音频、输出设置继续保留；原版涡旋作为默认分支不改动。
