# 画质、层次与连续形变

用户确认重点恢复「原生混沌」的质感。保留其原始卷曲算法和所有 19 个场景编号，基于已有原生截图作对照；增强整个输出管线，不替换成新的几何图案。改动前源代码保存于 `.runtime/before-quality-2026-10-03`。

1. 增加流畅 / 细腻 / 极致画质档，按屏幕像素密度渲染，取消体积场固定低精度限制。支持半浮点场缓冲以减少暗部色阶。MilkDrop 按档位提高源分辨率，极致上限 2560×1440。
2. 统一形体合成加入屏幕空间法线、方向光、软遮蔽与克制高光。保留暗部、避免大面积漂白。Oklab 连续上色代替每个色槽内的 smoothstep 平台，完善有明暗层次的色板。
3. 将静态叠化替换为受两幅场的轮廓驱动的连续位移形变；两端精确回到原图，可中断并保持当前可见帧。A/B 共用同一形变方式。
4. 后续视觉默认缓慢漫游构图：确定性随机目标、平滑插值、形体尺度/偏移/扭转/形态变化。提供「下一构形」和漫游开关，强度保留在预设参数中，Freeze 保持全部状态；前三套原始视觉不自动打乱。
5. 根据用户补充，光影界面只保留一个「层次」滑杆。把控制收进已有「表面与细节」，画质档在设置页。验证画质选择、旧预设兼容、随机演化边界、暂停、过渡两端和中断；浏览器批量检查原生、体积、几何、开源及 1080p / 窄屏。

这是实时的艺术光照与二维形变，不声称对任意开源预设恢复物理 3D 几何或计算真实光线追踪。
