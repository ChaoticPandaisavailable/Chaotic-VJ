# Visual Variations Implementation Plan

**Goal:** 在保留原生混沌的前提下，加入点阵、像素、轮廓、ASCII、汉字、三维粒子云与几何叠影，以及统一的二维和谐色彩宏。

**Architecture:** 形体、表面表达、色板、运动分别控制。原标量场继续使用 R8 缓冲；粒子用静态参数几何在 GPU 上计算三维位置，再进入同一配色链。表面模式使用连续权重，跨形体利用场历史渐变，不重置时钟和色板。颜色使用精选色板锚点的 Oklab 插值。

**Tech Stack:** 现有 TypeScript / Three.js / WebGL2 / Canvas 字形图集 / WebSocket；不新增运行依赖。

## 用户参考与选择

- 图 1–4：三角叠影、清晰的前后层级、半色调与像素。作为可选几何形体，保留流动，避免把原生混沌替换为硬切片。
- 图 5：薄纱状环面粒子云，有中心负空间、层层折叠、慢速旋转。需要真实三维粒子投影；字符须随粒子运动。
- 图 6–10：同一形体可转换为轮廓、点阵、像素、颗粒、负形等表达。首轮实现六种可连续转换的表面模式、简繁与呼吸，不声称完整复刻 50 种参考。
- 采用共享流场 + 独立粒子场的组合。全场景双渲染会翻倍重负载；纯屏幕滤镜不足以表达粒子空间，因此只在粒子形体启用额外粒子绘制。

## 执行与验证

1. `packages/shared/config.ts` 加入带默认值的变体、色彩宏配置，保留 v1 旧预设兼容；增加粒子与几何预设。测试旧配置迁移及新参数范围。
2. `packages/shared/palette.ts` 实现精选暖冷 × 柔浓色板和 Oklab 插值。测试全部网格点色域、亮度顺序、相邻连续性。
3. `packages/visual-engine/variations.ts` 管理表面权重、简繁、旋转、自动呼吸的连续状态；`glyphs.ts` 创建一次字形图集。测试快速切换与帧率独立性。
4. `packages/visual-engine/particles.ts` 创建静态粒子参数、三维形变、稳定随机字形与 GPU 点精灵；几何后续按原参考图重写为 `facet-composition.ts`，见 [参考图重构](2026-10-02-reference-refinement.md)。
5. `fields.ts` / `shaders.ts` / `index.ts` 接入共享配色、表面渐变、复杂度与旋转；粒子资源按需创建和释放；保持照片清除与冻结行为。
6. `apps/performer/src/variations-ui.ts` 和样式接入模式组、简繁/旋转/过渡、自动呼吸与二维色彩板。鼠标、触控、键盘可用；保存和导入共享现有配置。
7. `npm run build` / `npm test`；浏览器实际检查六种表达、两种新形体、颜色拖动、快速切换、Freeze、照片以及输出。测量条件写入 `docs/LOCAL_VALIDATION.md`，保留截图。

颜色数学参考：[Oklab 作者公开实现](https://bottosson.github.io/posts/oklab/)。视觉素材仅作为用户提供的设计参考，不上传或嵌入第三方素材。
