# 柔和层次、稳定工具栏与 GPU 负载

用户的新参考是 Inigo Quilez 的嵌套 fBm 图：细纹由连续形体承载，大块柔和明暗形成深度。上一版近像素法线、镜面高光和残留反锐化造成金属浮雕感，应移除。

1. 原生混沌保留嵌套 domain warp，压低尖锐周期脊线。根据用户对中间版本的反馈，恢复大块留白和疏密变化：纹理集中在形体内部，不再均匀铺满画面。增加一层细节采样；无声音时不重复计算音频扰动。
2. 阴影在低分辨率 GPU 通道中柔化，再以宽缓明暗调制原画；不沿细线生成高光。Oklab 配色先生成小型 GPU 查找纹理，避免每个全屏像素重复转换。
3. 单路输出跳过多余混合通道。独立输出工作时降低控制台预览开销；重复输出页待机。自适应精度降低快、恢复慢，避免反复重建全尺寸纹理。
4. 输出状态仅有一个更新入口，状态和性能分开固定位置；工具栏固定尺寸，并只在鼠标靠近底部时显示。控制台无配置变化时跳过整面板重复 DOM 写入。
5. 检查实际图形、A/B 端点与混合、冻结、工具栏连续更新宽高。保存前后截图，记录实际输出尺寸与 GPU 耗时；尺寸不一致的截图不用于计算性能提升百分比。保留用户色板、MIDI 与场景编号。
