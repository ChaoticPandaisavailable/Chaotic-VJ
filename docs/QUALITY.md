# 画质与构图优化 · 2026-10-03

本次重点是原生混沌的细节与前后层次。保留原始卷曲算法，恢复大块留白与疏密变化，把细纹集中到有形体的区域。去掉反锐化、细线法线与镜面高光：阴影单独在小型 GPU 通道中柔化，原始亮度场不做模糊。界面沿用一个“层次”滑杆。这是艺术明暗处理，不是物理光线追踪。

## 使用

- 设置 → 画质档位：流畅 / 细腻 / 极致。细腻是新默认值，旧 JSON 会补齐新字段。切换档位会恢复对应精度并降低颗粒、色差；自定义 HEX、XY 范围和 MIDI 映射保持原样。
- 表面与细节 → 层次：0 回到平面明暗，1 增强前后关系；默认 0.72。
- 构图漫游：后续视觉缓慢改变位置、比例、扭转和形态；几何面片会分别改变位置、大小与角度。前三套不参与自动重组。
- 下一构形：约 5 秒内渐变到下一组目标。演化速度控制自动漫游节奏。停止漫游时回到中性构图；关闭漫游后仍可手动生成并保持新构形。
- 换场：默认 3 秒。旧画面和新画面的轮廓共同引导位移，再逐渐替换亮度场；快速重选从当时的可见画面衔接。A/B 使用相同形变。
- 颜色 XY 使用完整色环与主辅色关系，提供 16 个配色起点与 90 / 180 / 360 秒慢变。全部色彩宏保留由暗到亮的明度关系，自定义 HEX 独立保留。

## GPU 与窗口调度

- 阴影用独立的、最大 480×270 的 GPU 明暗场计算。仅该通道进行两次可分离模糊，再调制清晰的主场。去掉全屏邻域反锐化及逐细线高光。
- XY 配色在 Oklab 中连接主色、柔和点缀与纯白，限制色彩数量并压缩越界色度，每帧生成 256×1 查找纹理，主画面使用一次采样；自定义 HEX 沿用 Oklab 插值。自动变色不增加全屏后处理通道。A/B 位于端点时跳过额外的全屏混合。无音频冲量时，原生混沌跳过音频扰动计算。
- 主输出默认跟随浏览器刷新回调，也可在设置中选 60 / 120 / 144 / 165 FPS 上限。控制台缩略预览为 30 FPS、最大 720 像素宽；全屏预览 30 FPS、恢复完整尺寸。重复输出页和隐藏的非主预览不绘制。
- 自适应在持续负载约 1.5 秒后降档，连续有余量 18 秒后才逐步恢复，减少渲染目标反复重建。
- 输出工具栏的动作、状态与性能分别固定位置，数字采用等宽字形。取消工具栏背景模糊，统一状态更新入口；空闲 3 秒隐藏，靠近底部或点“控制”显示。
- 超过 3.5 秒未提交画面的旧预览可以由新可见控制台接管；已有正式输出不被预览抢占。避免当前控制台无故一直停留在低帧率。

## 精度

| 档位 | 最大设备像素倍率 | 自适应精度下限 | MilkDrop 源上限 | 体积采样 |
| --- | --- | --- | --- | --- |
| 流畅 | 1 | 50% | 960×540 | 20 |
| 细腻 | 1.5 | 75% | 1920×1080 | 28 |
| 极致 | 2 | 固定用户设定 | 2560×1440 | 36 |

内部精度下限不会超过用户主动设定的内部精度。开源源图不放大到超过当前场尺寸；对应形变网格为 32×24、48×36、64×48。设备支持浮点颜色附件时使用半浮点场缓冲，否则回退到字节缓冲。基础输出按屏幕与设备像素密度计算，上限 3840×2160；用户设置的画质比例再乘到该尺寸。

## 前一轮验证与边界

2026-10-04 配色更新验证：构建与 49 项测试通过；蓝金、青紫和琥珀青碧实际输出无 shader 报错，慢变冻结截图内部像素差为 0。本轮浏览器已使用 RTX 4070 Laptop GPU；原生混沌在 1920×1080 输出与完整内部场精度下短时约 240 FPS、GPU 0.3–0.4 ms。当前实测取代下文先前 Intel UHD 的设备状态，不作为渲染算法提速比例。详见 [动态配色验证](plans/2026-10-04-color-harmonies.md)。

高刷补充：解除应用的 60 FPS 限制，支持跟随屏幕或有限上限。构建及 44 项测试通过，覆盖 60–240 Hz 模拟回调的调度、上限切换与配置保存；模拟回调不作为实际硬件帧率。浏览器中把上限改为 120 再恢复跟随屏幕，画质档、比例、内部场设定、自适应开关和色板均保持不变。

当前用户选中体积风暴，实际使用 Intel UHD，输出 1463×1307、内部场 1097×980，约 39–44 FPS、GPU 18.5–18.8 ms；该效果此时受 GPU 负载限制，未验证达到 120 FPS。系统只读枚举同时发现 RTX 4070 Laptop GPU。主渲染上下文已有 `powerPreference: high-performance`，但它不是显卡强制选择。若需切换，Windows“系统 → 屏幕 → 显示卡/图形”可以为实际输出应用选择高性能 GPU，保存并重启该应用后，仍须以设置页报告的 GPU 为准。[Microsoft 操作说明](https://support.microsoft.com/en-us/windows/hardware/display-graphics/optimizations-for-windowed-games-in-windows-11)。本轮没有修改系统 GPU 分配或重启 Codex。
