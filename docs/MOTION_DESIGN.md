# 节奏可以改变整个构图

最终方向：自然地观察风暴，保留原版多层混沌，不接受简单化和横向硬切片。材质与构图动作仍分开，但大块运动改为连续拉扯、环流和有阻尼的推移。优先三个入口：原生混沌、体积风暴、弦流云幕；六个较早的材质实验收进折叠区域。

| 动作 | 画面行为 | 音乐关系 | 当前实现 |
| --- | --- | --- | --- |
| 缓慢流动 | 大形体漂移，内部持续演化 | 留给间奏、铺垫 | 已实现 |
| 大幅扫场 / 回弹 | 整片形体横扫、轻旋转、撞击后回弹 | 连续推移 + onset 冲量 | 已实现 |
| 双团对冲 | 左右两半相向挤压、反向错位 | 低频增加压力，瞬态触发收缩 / 回弹 | 已实现 |
| 蓄力释放 / 穿行 | 收紧、扩张、旋转推进 | 16 拍周期的蓄力，瞬态释放 | 已实现 |
| 柔性拉扯 | 大片区域反向流动，连续过渡，不切成横向条带 | onset 施加阻尼位移 | 已实现 |
| 旋转游走 | 主体绕偏移中心旋转、盘旋 | 节拍压力 + 冲量偏转 | 已实现 |

三层时间尺度：帧间连续的流动；鼓点上的短动作；16 拍周期的大呼吸。默认使用自然漂移，强动作按需选择；避免每个鼓点只改变整屏亮度。颜色始终由当前色板决定。

体积风暴沿相机射线采样三维云密度，累积透射和光照，呈现近远遮挡。弦流云幕将连续四维场在 x/w、y/w、z/w 平面旋转，再在三维体积内观察其交织结构。这是高维图形启发的艺术场，不是超弦理论的物理模拟。体积场用有限步数和较低内部精度控制开销。

回弹采用带阻尼的质量弹簧，onset 上升沿施加冲量。运动积分用小步长，避免低帧率时发散。GPU 只负责将这个统一动作应用于坐标场，不为每个像素重复模拟物理。

## 最终鼓点响应

根据后续反馈，撤掉了外加亮色笔迹，也不绘制可见的装饰圆环。Kick 检测使用 35–180 Hz 的正向频谱变化，独立于普通 onset。触发后记录固定的空间落点、随机方向和强度，之后连续演化；不会每一帧重新抽随机位置。

- **亮块推移**：现有白色 / 浅色大块有更强的位移，周围暗部保留不同的运动幅度。
- **涟漪扩散**：通过采样坐标的连续形变传递冲击，不用额外线条覆盖画面。
- **惯性游走**：整幅构图获得小幅随机速度，带阻尼地滑行和回流，减少节拍上的硬停顿。
- **节拍色彩**：在当前色板内平滑改变中间层的颜色分布，保留亮部，强度独立可调。

高频不再直接高速改变噪声频率。每 0.75–1.55 秒更新一次随机目标，以约 0.6 秒时间常数平滑，只影响较弱的局部轮廓 / 细节；普通高频 onset 对大结构的影响也显著降低。

## 底层性能策略

256×256 RG 噪声查找表在 GPU 中复用，两个相邻体积切片 / 两路 domain-warp 噪声用一个采样获得。原生混沌保留五层 FBM，但合并成对采样。每个材质有独立的编译常量和缓存程序，切换期间用历史场平滑过渡，避免每帧同时完整计算两个重材质；新程序通过 Three 的异步编译接口准备。

背景使用单通道 R8 双缓冲；照片仅在需要时分配自己的 RGBA8 双缓冲。画面纹理与最终输出分辨率分开，亮块位移和色彩在最终输出像素上合成。自适应优先看异步 GPU 时间，避免把浏览器后台调度变慢误判为 GPU 不够快。没有 GPU 计时扩展时才用帧率作回退依据。

可以继续扩展、目前没有实现的编舞：

- **卷帘与翻页**：从边缘卷入一整片材质，重拍落下后展开。
- **聚合 / 爆散**：多个大块向一个中心聚集，drop 时抛向画面外，再形成新构图。
- **遮挡式换景**：巨块遮满画面，在遮挡期间更换底层材质，随后扫开。
- **队列追赶**：大形体错开半拍依次运动，让节奏沿空间传播。
- **悬停 / 释放**：break 时保持大结构，细节继续流动；drop 时恢复惯性。
- **编舞序列**：按 4 / 8 / 16 小节安排动作，不只是随机轮换预设。

下一轮应根据真实音乐判断动作幅度、重拍与段落关系，而不是不断增加细碎噪声。当前内部 / Tap 节拍不等同于真实歌曲段落识别；VDJ 拍位接入前不宣称自动识别 drop。
