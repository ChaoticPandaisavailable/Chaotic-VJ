# 实时低频冲击与气流

当前版本采用本地 DSP，不使用 Stem 模型、服务器推理或 BPM 合成鼓点。检测时机与冲击力度分开：相近的实测低频力度得到相近的推动，检测置信度不再决定画面有多重。

## 信号路径

- **起音快路径**：30–170 Hz 的能量突增，由 180–1800 Hz 攻击成分交叉确认，约 12 ms 候选确认。
- **强 Bass 下的补充路径**：立体声短时频谱的正向变化、逐频点衰减基线与对数压缩，联合低频和中低频证据。高于 200 Hz 的邻频最大值抑制滑音误触，另有低频占比检查。48 kHz 下窗口 2048 样本，步长 256 样本；只读已发生的声音，没有未来缓冲。两条路径共用 150 ms 防重复触发间隔。
- **冲击力度**：仅在分析支路使用 20 Hz 高通、200 Hz 四阶 Butterworth 低通，并对 80 Hz 附近加权。能量权重为 70% 中心频带、30% 整体低频，固定幅度增益 1.4，6 ms 上升 / 45 ms 释放。没有逐拍自动拉满或 AGC，也不改变观众听到的声音。
- **画面包络**：鼓点打开短时门控；6 ms 上升，前 85 ms 保留实测力度窗口，之后按 70 ms 时间常数消退。这个窗口立即响应，不是等待 85 ms 再显示，避免相同鼓因检测早晚相差十几毫秒而忽轻忽重。
- **Bass 流动**：持续低频独立推动分层气流，85 ms 上升 / 220 ms 释放；高频继续控制微光和星点。静音后音乐施力消退，自然演化继续。
- **大范围推动与长释放**：已撤回上一轮即时加速与震动放大，恢复原有局部运动。新增气体整体的压力推移，55 ms 进入、240 ms 释放时间常数，典型单次鼓点约半秒到一秒收尾。前、中、后层按 1.25 / 1 / 0.55 的位移比例自然错动，星空保持独立。压力积分为有限范围内的连续位置，释放只减速、不弹回，不积累贴图边框；持续 Bass 不触发这一路。起音识别与 80 Hz 实测力度不变。

AudioWorklet 每 128 样本分析一次，击中时立即通知页面，平时约 60 次/秒。只向画面及本地输出同步数值，不发送 PCM。超过 120 ms 的旧事件丢弃，不排队补播。反相立体声分别计算能量，避免单声道相消。工作线程不可用时，界面明确标示兼容检测，此时仍使用旧分析器。

“音乐施力 → 识别与校准”可以调灵敏度。它决定是否触发；“冲击”决定视觉参与强度。算法不接收歌曲名、段落时间、BPM 或拍号。Tap Tempo / VDJ 节拍仅作参考。

## 验证：Duro 的 Drop

2026-10-09，使用用户提供的本机 MP3 解码为 48 kHz 立体声，将真实 PCM 逐块送入同一检测器、事件邮箱和 MusicForces；画面调制以 120 Hz 离线模拟。150 BPM / 4/4 拍仅用于事后核对，不输入运行算法。

- 54.4–60.4 秒的前两个八拍，16 次起音全部检出。
- 音乐参与度与冲击均为 1 时，前 16 拍冲击峰值为 0.848–0.871，变异系数约 0.82%。这是调制数值一致性，不是像素运动完全相同的承诺。
- 65.6–66.8 秒最后四拍，加权低频峰值分别约 0.294 / 0.427 / 0.324 / 0.301，普通 Drop 约 0.904。对应冲击约 0.005 / 0.291 / 0.005 / 0.290：其中两拍触发较弱，两拍未过起音门限，没有按节拍补强。这验证了能响应低频削弱，不代表能识别制作人使用的具体滤波器。
- 全曲触发数由旧能量路径的 107 次变为 304 次；这只是比较计数，未经人工逐事件标注，不是准确率。

本机测量数据和对照图保存在忽略目录 `.runtime/audio-validation/`，包括 `drop-report.json`、`drop-beats.json`、`duro-drop-proof.png`。用户歌曲及解码音频不进入 Git。

## 对照信号与开销

“低频对照”播放 18 秒原创声音：Bass → Kick → 强 Bass + 轻 Kick → Bass → 静音。声音经过真实分析链路，不直接注入视觉事件。停止按钮结束播放。

```powershell
npm run audio:benchmark
npm test
npm run build
```

本机 i9-14900HX：18 秒信号计算约 493 ms，单个 128 样本块中位数约 0.110 ms，P99 约 0.203 ms。16/16 目标鼓点检出，无额外触发；检测延迟约 5–31 ms。这里是离线检测开销，不是完整应用 CPU 占用或声卡到屏幕的端到端延迟。

完整测试 120 项与生产构建通过。覆盖 44.1/48/96 kHz、反相立体声、强 Bass 掩盖轻 Kick、振音低音叠加踩镲、压缩混音、静音、显示卡顿、力度比例、检测时机抖动、不同 BPM、七个八分音符分组与休止；输出服务验证并转发可选的低频力度数据，兼容旧客户端。

## 边界

这是混音中的实时瞬态估计，不是乐器分轨。猛烈起音的 Bass、低音 Tom、人声和严重压缩的混音仍可能误触；被大幅滤掉的鼓可能不触发。150 ms 间隔也会合并更密集的滚奏。不同拍号不需配置，但不能由这一首歌推断所有音乐都能完美识别。

算法参考了 [aubio 的谱白化、压缩与起音门限](https://aubio.org/doc/latest/onset_8h.html)、[SuperFlux 的邻频抑制思路](https://github.com/CPJKU/SuperFlux)及其 [DAFx 原论文](https://www.dafx.de/paper-archive/2013/papers/09.dafx2013_submission_12.pdf)。本项目为小型低频专用实现，不是这些库的完整移植。
