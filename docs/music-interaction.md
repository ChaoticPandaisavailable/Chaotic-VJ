# 音乐驱动卷流

声音推动已有纹理连续流动。低频作用于大尺度，中频作用于中尺度，高频作用于细流和局部微光；原生混沌的自然演化持续运行。手动宏值、配色和输出分辨率由演奏者控制。

## 2026-10-06 修复

上一版沿可见亮度的负梯度向外扩张，并移除了所有向内分量。这种速度场不保持面积；将其永久累积到 256 × 144 的材质坐标纹理，再对边缘取样夹紧，会逐渐造成坐标塌缩、巨型色块和固定台阶边框。“清空残影”还漏掉了输运图，无法恢复。

已移除这个累积输运图。现在用三组旋转坐标中的可逆剪切组成材质映射，每次直接在当前渲染像素计算。每个剪切的雅可比行列式为 1，组合仍为 1：同一块材质会流动、拉伸、转弯，但这层映射不会凭空增加面积。变形幅度、空间梯度与相位都保持有界，没有反复重采样导致的细节损失，也没有需要夹紧到屏幕边缘的历史坐标。

这是保持面积的程序化流动，不是完整的 Navier–Stokes 流体求解器。原生材质自身仍在演化，所以最终画面亮部面积并非恒定。保持面积是对新增输运映射的约束。

## 演奏

- **音乐参与度**：声音施力程度。0 时只保留自然演化。
- **推动**：低频起音推动连续的大尺度纹理；不按拍重新随机落点。
- **流动**：实时低频越强，大块卷流越快。持续低频的速度增益由 3.5 调到 4.8（约增加 37%），低频施力的起步平滑由 220 ms 缩短至 120 ms；保留速度上限和原有面积约束。
- **细节**：高频带动小尺度细流与边缘微光。
- **平稳 / 蓄力 / 释放**：由演奏者控制的段落动作，静音时也可手动触发。
- **TAP TEMPO / 对齐这一拍**：只调整节拍参考，不制造视觉鼓点。
- **画面延后**：0–250 ms 的视觉分析校准。

音乐只改变流动相位的推进速度，声音退去时速度平滑退去，相位继续沿原方向前进。不会将已经形成的位移拉回零点。基础运动在静音时继续，冻结时停止。

音频来自当前桌面输入或本地文件的实时频谱。低频突发还要求低频能量同步上升，减少单纯换音高误触发。这里只做频段近似分析，不声称精确分离乐器。MilkDrop 风格保留自己的 PCM 音频逻辑。

## Shuffle

形态面板提供单个 **Shuffle** 按钮，点击一次重新生成当前构图。支持鼠标、触屏以及键盘 Enter / 空格操作。

状态与基础随机种子共同决定构图，随预设保存；不改颜色、灯光、音乐、分辨率等设置。重新生成时清除流动相位、速度和历史帧。内部保留 000–127 的状态序列，以兼容已有预设。

MiniLab 学习列表新增 **Shuffle · 一键重排**，可绑定打击垫或 CC 按键：按下一次触发一次，按住和松开不重复。原来的连续状态映射仍能读取旧预设。

连续请求会合并，在输入停止约 120 ms 后应用，避免连续初始化导致抖动。冻结期间的请求在恢复后处理。“清空残影”同时清理流动状态与历史帧。

## 验证与限制

自动检查包括：30 分钟最大施力的加速数值测试、面积与可逆性、屏幕边缘外取样、空间连续性、静音与冻结、真实测试 WAV 在 30 / 60 / 144 Hz 下的频谱到运动链路、BPM 独立性、重置恢复、Shuffle 预设和 MiniLab 编码。

开发页 /music-check.html 增加 GPU 映射与 CPU 参考的一致性检查，以及长时间相位推进后圆形材质的面积检查。它不是生产页面。本轮浏览器测试连接无法启动，GPU 页面尚未实际执行；自动数值测试不替代现场观感、帧率和长时间 GPU 检查。

背景阅读：Bridson 等人的 [Curl-Noise for Procedural Fluid Flow](https://www.cs.ubc.ca/~rbridson/docs/bridson-siggraph2007-curlnoise.pdf) 讨论不可压缩程序化流场。这里采用可逆剪切映射，并非复现论文的 curl-noise 算法。
