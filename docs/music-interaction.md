# 音乐驱动分层气流

原生混沌现在使用前、中、后三层气体：主体保留既有的云海、水墨、星云、经典卷曲形态；近景薄雾与远景云气以不同速度和方向掠过。按前后顺序合成透明度，前面的气体可以遮住后面的云和星点，而不需要将整幅纹理一起拉扯。

## 运动与质感

移除全场共用的材质剪切映射。声音现在推进各层的空间位置；位置沿平滑、有界的长弧线移动，不反复累积图像变形或重采样历史坐标。各层速度不同，所以能产生穿行、覆盖和视差。

近、远雾层共增加六次噪声取样，没有将完整的主场景计算三遍。叠加次序采用前到后透明合成，并降低气体的浮雕阴影、镜面高光与历史帧残留，减少实体硬壳感。这是用于现场视觉的分层气体近似，不是完整三维流体动力学模拟。

云海风暴、水墨山海、熔流星云、经典卷曲共用两档疏密与大小不同的星点。星空从屏幕空间单独生成，位置不随气流扭曲；三层气体的透射率控制星点被遮住或重新显露。

星点各自缓慢闪烁，实时高频与起音通过现有“细节”控制增强随机一部分星点。静音时只保留微弱的自然明暗变化，不按 BPM 制造闪光。星空时钟独立于音频推动的气流时间，冻结与 Blackout 会同时暂停。

熔流星云取消了随气体时间持续增长的整体旋转，也不再跟随主体云层的固定圆形轨迹。改为小范围的随机中心游移与两处独立局部卷动：方向和停留时段随种子变化，使用缓入缓出的连续插值，顺逆方向都可出现。音乐继续推动内部翻涌；构图游移单独限速，强低频不会再把整个星云带着快速公转。其它三种意境保留各自运动。

流星采用单条解析尾迹，首次约 3–8 秒出现，之后间隔约 12–28 秒随机划过，路径、方向、长度与亮度随种子变化，淡入淡出并接受云层遮挡。切换四种意境会保留星空时序，Shuffle 重新生成种子。不新增后台渲染场景或离屏纹理；流星不活动时跳过尾迹计算。几何和其他独立场景不加这层星空。

原理参考：[NVIDIA GPU Gems — Volume Rendering Techniques](https://developer.nvidia.com/gpugems/gpugems/part-vi-beyond-triangles/chapter-39-volume-rendering-techniques)，尤其是 emission–absorption 和前到后合成部分。此处为原创的轻量分层实现，没有移植完整体积求解器。

## 实时音频

- **音乐参与度**：声音施力程度，0 时只保留自然演化。
- **推动**：低频起音推动云气，带轻微震颤。
- **流动**：实时低频越强，云层漂流和内部翻涌越快；0 会关闭持续低频推动。
- **细节**：高频带动前景薄雾与局部微光。
- **平稳 / 蓄力 / 释放**：演奏者控制的段落动作，静音时也可手动触发。
- **TAP TEMPO / 对齐这一拍**：仅节拍参考，不制造风、鼓点或震颤。
- **画面延后**：0–250 ms 的视觉分析延迟校准。

低频来自桌面输入或本地文件的实时频谱，起音还要求低频能量同步上升，减少换音高误触发。轻微震颤的包络由当前低频控制；低频退出后震颤停止，基础漂流继续。振动载波用于可见的低幅摆动，不是音频原始波形的逐样本复现，也不使用 BPM。

全局动画时钟不再受这套音乐施力加速。气流和新增细节光只作用于原生混沌（style 6）；几何、晶面、粒子、体积风暴等保留自己的原有运动，后续再分别设计声音映射。MilkDrop 仍使用其自身的 PCM 音频响应。

普通音乐与测试节奏的低频特征通常远小于 1。低频采用有界的软拐点响应曲线，不再乘一次整体 RMS 把小信号压掉；静音门限仍保留。气体专用的生长时间积分低频推动量，和层间漂流同时加速，停止施力后只回到原来的自然演化速度，不把图案倒放回起点。星点位置与其他场景的时间保持独立。

2026-10-06 使用界面同一份 test-beat.wav 做离线频谱回放对照（音乐参与度 1、流动 0.95、低频调制 0.5）：流动峰值从 0.112 提升到 0.403；音量乘 0.35 时从 0.037 提升到 0.185。这是分析与运动参数的数值对照，不是 GPU 画面或实际帧率测量。

## Shuffle

形态面板的单个 **Shuffle** 按钮按一次重排当前构图，保留配色、灯光、音乐和分辨率参数。支持鼠标、触屏和键盘 Enter / 空格。内部 000–127 状态与基础种子共同决定构图，随预设保存。

MiniLab 的 **Shuffle · 一键重排** 支持打击垫和 CC 按键；按住和松开不重复触发。连续状态映射保留旧预设兼容性。冻结期间的重排请求在恢复后处理。“清空残影”同时清理气流、微震和历史帧。

## 版本问题与验证

更早版本的亮部外扩不断累积，导致坐标塌缩、巨大色块和边框卡死。随后采用的有界剪切修复了累积问题，但统一坐标变形仍容易显得像橡皮泥；当前版本进一步取消它，改为分层移动和透明覆盖。

自动检查包含 30 分钟最大施力的加速数值测试、层位置连续性和范围、透明遮挡、低频强弱与速度、低频退出但高频仍在时的响应、BPM 独立性、30 / 60 / 144 Hz、真实 test-beat.wav 分析、冻结、重置和 MIDI。

开发页 /music-check.html 可检查 GPU 透明合成，以及几何/粒子取样在气流参数改变时是否保持原样。生产模式不提供该页。本轮浏览器测试连接仍因宿主沙箱启动失败，实际 GPU 画面与性能尚未复验；数值测试不替代观感验收。
