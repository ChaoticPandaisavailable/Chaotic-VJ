# MiniLab MkII 演奏

打开控制台的 **演奏 → 连接 MiniLab / MIDI**。键盘用 USB 连接电脑，并允许浏览器的 MIDI 请求。如果内置预览没有弹出授权提示，可取消连接，在 Chrome / Edge 打开同一个 `http://localhost:5174/` 页面。只打开一个控制台接收 MIDI；独立输出窗口通过现有同步接收参数。

## 两种切换

- **打击垫切场景**：展开“映射与旋钮范围”，目标选一个场景，点“学习”，再按打击垫。重复绑定需要的场景。音符松开不触发切换，CC 按钮仅在按下的上升沿触发。
- **旋钮连续混合**：在 B 下拉框准备另一种视觉，映射目标选择“A / B 混合”，点学习并转动旋钮。旋钮左端为 A、右端为 B，中间是两边实时画面的混合。旋钮会自动启用混合。
- **用打击垫准备 B**：将“场景按键装入”切到 B，已绑定的场景打击垫就会装入 B；再用混合旋钮进入。切回 A 可继续用打击垫直接切主画面。

建议先把 8 个打击垫绑定常用场景，把旋钮依次分给混合、色相、点缀、能量、密度、流速、复杂度、旋转。不预设固定 MIDI 通道或 CC 编号，保留键盘原有预设。

## 旋钮模式与范围

应用里的编码模式必须与 Arturia MIDI Control Center 设置一致。按 [MiniLab MkII 官方手册 §4.8.4.1](https://downloads.arturia.com/products/minilab-mkII/manual/MiniLabmkII_Manual_1_0_7_EN.pdf)：

| 模式 | 向左 | 向右 |
| --- | --- | --- |
| 绝对值 | 0–127 的当前位置 | 0–127 的当前位置 |
| 相对 1 | 61–63 | 65–67 |
| 相对 2 | 125–127 | 1–3 |
| 相对 3 | 13–15 | 17–19 |

相对模式中的中性 `00` 不改变参数；较快转动产生的 ±2 / ±3 步保留。绝对值默认启用接管：旋钮经过当前参数后才开始控制，避免突然跳变。每条映射都有起止范围，允许反向。此接口接收音符和 CC；键盘旋钮请用 Control 模式，NRPN/RPN 未实现。

颜色的演奏范围在 **色板 → XY 演奏区间**：设定色相与双色点缀的起止百分比，勾选限制。整个 XY 面板与旋钮行程会映射到该范围，不产生边缘大片死区。“缓慢变色”也遵守这个区间，旋钮改变漫游的起点；希望精确保持旋钮选色时关闭慢变。旧的暖冷、浓度映射继续有效，内部目标标识不变。直接编辑 HEX 仍能自由建立 3–5 色自定义色板；XY 操作不覆盖这些 HEX，选择“自定义 HEX”即可恢复。切换场景保留配色模式。

点“保存”可将 MIDI 映射、区间、B 视觉和混合值一起保存为预设。设备连接需要每次主动开启，不自动索取权限，不向键盘发送数据。

## 视觉衔接

普通切换保留正在显示的画面，以五阶缓入缓出接入新画面；连续按不同场景也从中断时的实际画面继续。出场画面作为轻微流动的纹理保留，进场实时演化。A/B 则是两个同时运行的实时场景。所有形态统一在混合之后上色。

更多形态的换场时长在 **表面与细节 → 过渡 / 秒** 调节。前三种互切沿用 1.2 秒；原始三套场算法未改。Freeze 暂停两边的形态演化和过渡进度。

软件构建、协议测试和浏览器交互已验证。真实 MiniLab 接入、旋钮方向、端口独占情况与现场输出负载，需要连接实物后确认。本次内置浏览器停留在 MIDI 授权请求，没有取得实物输入。
