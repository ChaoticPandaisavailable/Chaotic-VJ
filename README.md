# Chaotic-VJ / Realtime Visual Instrument

本地运行的音乐驱动视觉乐器：大画面演奏台、十一个精选视觉入口、可编辑色板、桌面音频分析、照片融合与手机上传。

## 当前版本 · 2026-10-13

- 视觉库分为两组：混沌与星空（熔流星云、云海风暴、水墨山海、经典卷曲、深空涡旋、极光风幕），空间与形体（体积风暴、弦流云幕、粒子花云、几何叠影、潮汐光池）。
- 六个可编排演出快捷位与效果搜索；Shift 先排入下一幕，Enter 切入，Escape 取消。
- 大画面优先，右侧按画面、配色、音乐、现场、输出分组；支持专注画面和键盘切换参数页。
- 四种混沌共用分层星空，高频让部分星点短暂轻微变大、变亮；云海减少密集碎纹。粒子花云循环开合，深空涡旋默认保留原旋臂，并提供星风、双星流两种附加形态。
- 十一个视觉入口均有符合自身结构的音乐响应：Kick 推进或激发局部运动，Bass 持续输送，高频点亮星尘、纤维或边缘；不靠全局缩放制造节奏。
- 连续 XY 配色、七套电影意境、自定义颜色角色、预设保存 / 更新、YOUR PALETTE 重置与撤销。
- 点击后按需准备目标视觉，再连续过渡；支持 MiniLab MkII MIDI Learn 与 A/B 混合。
- 控制台右上角和独立输出页可选自动、1080p、1440p、4K；固定档按所选尺寸完整渲染。
- 修复新意境内部运动过慢的问题，静音时也会持续演化；流速、Freeze 和 Blackout 保留。

MilkDrop 全组、液态洪流、细胞脉冲、晶面裂变、磁流丝带、断层风暴和等高线表面已移出选择界面；MIDI 新映射和 A/B 选择同步精简。底层历史索引及配置解析保持兼容，不重编号旧预设。

2026-10-05 的历史备份参数见 [`presets/11-current-backup-2026-10-05.json`](presets/11-current-backup-2026-10-05.json)。这是配置快照，照片、会话、管理密钥和本地运行目录不随仓库发布。历史文档中的性能结果对应各自日期与版本，不能视为当前硬件上的帧率保证。

## 启动

首次安装需要 Node.js 22.12+ 和网络。已在 Node.js 25.8.0 / Windows 本机构建。

```powershell
git clone https://github.com/ChaoticPandaisavailable/Chaotic-VJ.git
cd Chaotic-VJ
npm ci
npm run build
npm start
```

打开 <http://127.0.0.1:5173>。以后可以双击 `启动VJ.cmd`：它会构建并启动本地服务。开发修改用 `npm run dev`。退出服务按 Ctrl+C。

如果端口已在运行，直接打开页面；不要同时启动多个实例。可用 `$env:PORT=5174; npm start` 改端口。照片和状态保存在 `.runtime/`，默认不进入源码仓库。

## 先看效果

1. 在“音乐”页点击“测试节奏”，播放项目原创的 30 秒 / 120 BPM 测试音频；或选择“本地音乐”。文件只在浏览器本地解码。
2. 在画面下方的视觉库按分类选择效果，默认 3 秒渐变换场并保留当前色板。混沌内部切换四种意境会保留已调参数；从其他效果进入混沌、体积风暴或弦流云幕时恢复连续表面及原始运动表达。
3. 在“画面 → 构图与流动”选择缓慢流动、整团推移、环流对冲、蓄力舒展、柔性拉扯或空间盘旋。“幅度”控制位移，“形体尺度”越大，主形体越大。
4. 基础宏与残影细节位于“画面”，照片强度位于“现场”，声音参与度和各路响应位于“音乐”。控件按当前效果显示，声音参数与基础形态分开。
5. 在“配色 → 自定义色槽与明暗”编辑 3–5 个颜色与背景色，支持 HEX、重置与撤销。锁色默认开启，照片只提供纹理和明暗。“保存”打开“现场”的预设库，可新建、更新、载入或导出 JSON；“输出 → 导入 JSON 预设”恢复导出的配置。`presets/` 保留历史参数起点。

“粒子花云”以花瓣曲面循环绽放、舒展、聚拢，完整周期为 24 个视觉时间秒，实际时长随流速变化。Kick 依次带动不同花瓣局部折展，Bass 沿织物传递波动，高频点亮部分纤维；中心保持连接，Freeze 停住周期与音乐形变。连续、点阵、像素、ASCII、汉字沿同一形体演化。在“画面 → 表面与演化”调整复杂度、旋转和颗粒大小。`presets/10-silk-flow.json` 保留青瓷薄纱的历史参数，可在“输出”中导入。

“极光风幕”由三层带细纤维的光帘组成，低频输送褶皱，鼓点产生穿过光幕的局部光浪；“潮汐光池”由交叠波面与折射亮线组成，鼓点在不同落点产生向外传播的涟漪，高频点亮少量波峰。连续鼓点最多保留六道独立光浪，不会让后一拍重置前一拍。新视觉使用原生 GPU 着色器，不加载历史 MilkDrop 引擎。

“演出快捷位 → 编排”可给 1–6 分配效果或空位，保存在本浏览器。数字键或点击直接切换；Shift+数字、Shift+点击效果排入下一幕，当前画面继续播放；Enter 切入、Esc 取消。下一幕只暂存效果选择，切入时沿用现有异步准备与平滑过渡，不是离屏预览。输入框、下拉菜单和弹窗中不触发演出快捷键。按 `/` 搜索名称、描述或分类，多个词同时匹配；搜索框中的 Esc 清空搜索并移开焦点。

本轮参考 [ahLOOKah 的操作布局](https://ahlookah.com/docs/interface.html)、[分类与参数](https://ahlookah.com/docs/patterns.html)及[演出快捷位](https://ahlookah.com/docs/slots.html)。着色器独立实现，保留本项目的大画面布局、当前配色及既有视觉。

“颜色 XY”左右遍历完整色环，下方是主色到白，上方逐渐加入柔和的辅色点缀；深处收为近黑，高光可以达到纯白，中间调保留明确主色。方向键微调、Shift 加速、双击回中；下拉菜单提供 16 个配色起点、自由 XY、黑白和自定义 HEX。勾选“缓慢变色”后整套配色连续演化，可选 90 / 180 / 360 秒一圈，默认 180 秒；白点显示正在播放的位置。关闭慢变会平滑回到选定位置。启用 XY 演奏区间时仅在区间内往返；Freeze 和 Blackout 暂停颜色演化。所有形体共用配色，XY 和 MIDI 操作不会覆盖自定义 HEX 色板。配色依据与实现见 [动态配色](docs/plans/2026-10-04-color-harmonies.md)。

“几何叠影”使用大三角切面、半透明叠层、抗锯齿细线与局部网点。实测 Kick 推动六组面片切换扇形、对列、斜列和开弧队形，Bass 带动局部漂移，高频点亮边缘；不按固定拍号生成换位。移动真实顶点以保持直线，密度与复杂度调节层数，碎裂调节印刷纹理。

“深空涡旋”默认恢复原来的旋臂、云雾、暗心与细尘；“星风”和“双星流”作为附加形态选择，分别呈现宽幅星尘风带与两个大小不同的旋臂中心，切换时平滑混合。Kick 宽缓推进涡流，Bass 沿旋臂或风带持续输送，高频局部点亮尘粒；停声后推进逐渐收住，不把整幅画面放大缩小。

当前 XY 已提高主体亮度与色彩强度，可从“晴蓝 · 金黄”或“琥珀 · 冰蓝”开始。明暗层次独立于色相，纯白高光和暗部留白继续保留；三类色觉差异的近似检查用于发现层次合并，实际观感仍应按使用者调整。

体积风暴保留原有体积形态：Kick 推动不同深度的内部云层，Bass 输送云气，高频照亮薄边；固定的体积范围避免长时间漂移后画面空掉。弦流云幕保留大弦面和深度留白，Kick 沿弦面发出衰减波，Bass 带动连续漂移与内部变形，高频点亮局部丝线。调整“形体尺度”和动作幅度时会平滑衔接。点击对应视觉入口载入参数，同时保留当前颜色、慢变与 MIDI 设置。

动作设计和下一轮方向见 [构图与节奏](docs/MOTION_DESIGN.md)。来源及实际观察见 [参考记录](docs/REFERENCE_STUDIES.md)。

“音乐 → 鼓点响应”提供推动力度、作用范围、流动平滑，供混沌气体调节响应。Kick 推动已有云体，释放后逐渐减速，Bass 继续独立带动流动；星空保持独立时钟，不随气体整体移动。

“画面 → 打光与层次”控制主光、阴影、光照方向和立体程度。“表面与演化”中的构图漫游缓慢改变比例、位置和形态；“下一构形”平滑进入新构图。混沌、体积风暴与弦流云幕保留自身运动，不提供附加漫游。颜色与自定义 XY 区间独立保留。画质与验证记录见 [画质优化](docs/QUALITY.md)。

## 桌面音频

点击“连接桌面音频”，在浏览器授权界面选择整个屏幕，并勾选共享系统音频。实际是否提供该选项取决于浏览器和系统；以成功取得 audio track 为准。没有共享音频或选择浏览器标签页时，应用会提示重新选择；窗口音频会标示为窗口来源，需核对是否包含 VDJ Master。不会用麦克风替代桌面声。

捕获流可能附带视频轨，代码不显示、录制或上传桌面画面。桌面声仅进入分析，不再次播放，避免回声。本地文件和测试节奏会正常播放。点击“停止”可停止采集。

所有效果共用实时音频检测：音频线程联合低频起音与频谱变化识别 Kick，减轻强 Bass 对轻 Kick 的掩盖；力度跟随 200 Hz 以下的实测能量，重点加权 80 Hz 附近。持续 Bass 与高频单独映射到各效果的流动和局部细节。检测置信度不再决定冲击大小，也不按 BPM 或固定拍号补鼓；静音时继续自然演化。无需分轨模型或服务器推理。“音乐施力 → 识别与校准”可调底鼓灵敏度。

音乐运动采用平滑的 Kick 起落和累计漂移。声音停止后新增施力退出，已输送的纹理位置保留；Freeze 同时保持自然周期、音乐包络与漂移进度，恢复时继续。不同效果保留自己的形变方式，几何仍使用真实面片换位，混沌仍使用分层气体推动。

点击音频区的“低频对照”，可依次听到 Bass、Kick、两者叠加、Bass、静音，直接核对流动与冲击是否分开；点击“停止”结束。它播放真实生成的声音，画面依然通过同一套实时检测响应。检测能力、延迟测量及局限见 [实时音频说明](docs/REALTIME_AUDIO.md)。Tap Tempo / VDJ 节拍仍作为参考，不用于生成鼓点。

## 性能与输出

“颜色方案 → 电影意境”提供暮色与余晖、生机草甸、沉金极夜、霆霓风暴、棱镜全谱、雪域苍松、地心熔流。雪松以雪白为底、松绿为主体，暮色用浅桃色留白、烟粉与深紫，棱镜用珍珠浅底；草甸、熔金、风暴、熔流分别使用林绿、深褐金、夜蓝、炭黑红的明暗关系。意境内的 XY 调整色调与染色，缓慢变色在该方案内往返；“自由 XY”继续遍历全色相，HEX 与 MIDI 区间保留。亮部弥散由“输出 → 微光”控制，置零关闭；光晕以最大 320×180 的独立 GPU 纹理计算，主体清晰度不变。说明、参考与备份路径见 [电影意境调色](docs/plans/2026-10-04-cinematic-color-design.md)。

切换视觉采用按需准备：点击后当前画面继续播放，目标着色器与几何就绪后才开始完整过渡；连续点选以最后一次选择为准。不会在启动时遍历渲染所有风格。过渡期间旧场景继续运行，以局部柔和交界逐步让出画面；遮住的区域跳过复杂场计算。新场景使用独立历史，避免旧纹理残留。连续快速点选会等待当前交接完成，再转向最后选择的场景。首次选择复杂效果可能稍有等待，准备阶段仍可能短时增加 GPU 负载。实现与验证见 [按需平滑切换](docs/plans/2026-10-04-smooth-transitions.md)。

自动分辨率档按设备像素密度与画质档渲染；细腻档自适应最低 75%，流畅档允许降到 50%，极致档保持设定精度。固定 1080p / 1440p / 4K 档锁定输出和内部场尺寸，优先保证画质。体积采样随画质档提升。“输出 → 输出帧率”默认为“跟随屏幕 · 高刷”，也可选择 60 / 120 / 144 / 165 FPS 上限；实际帧率取决于 GPU 负载与浏览器回调。已有输出时，控制台预览限 30 FPS，并按画质和设备像素密度保留较高分辨率；预览尺寸和正式输出尺寸分别显示。重复输出页和隐藏的非主预览暂停绘制。

“输出”显示实际输出尺寸、内部场尺寸、GPU 型号；设备支持时显示异步 GPU 时间。自动分辨率档可以调整画质比例与自适应；固定分辨率档保持指定像素尺寸，窗口大小不改变输出尺寸。性能结果及边界见 [本机验证](docs/LOCAL_VALIDATION.md)。

输出页还会显示 CPU 绘制提交耗时和浏览器动画回调频率。内置预览被隐藏时可能被浏览器限制到 1 FPS；正式输出应保持独立窗口可见。自适应优先使用 GPU 耗时，持续超预算约 1.5 秒后降低内部精度，连续有余量 18 秒后才逐步恢复，避免精度反复跳动。后台限帧不会直接触发降低清晰度。控制台分别显示本页预览帧率和实际输出帧率。

点击“独立输出”，将弹出的窗口拖到 HDMI 扩展屏，在该窗口点击“连接桌面音频”，然后全屏。工具条采用固定布局，闲置 3 秒自动隐藏；鼠标靠近底部或点击右下角“控制”可显示。输出窗口接管播放时，控制台停止原音频采集并降低预览频率。控制台仍可调参，也可收起。第二个输出窗口不会抢占已有输出。若旧预览页已超过 3.5 秒没有提交画面，新可见控制台可接管该预览；正式输出不会被预览抢走。

Freeze 冻结场与照片时钟；Blackout 输出黑色并暂停照片时钟；暂停队列只暂停照片。快捷键在浏览器获得键盘焦点时有效：Ctrl+Shift+空格为 Freeze，Ctrl+Shift+B 为 Blackout。全局快捷键未实现。

## 照片与手机

“添加照片”支持 JPEG、PNG、WebP，每张最多 12 MB、解码最多 4000 万像素。HEIC 请先导出 JPEG。服务端异步缩放到最长边 1536 px，移除元数据并生成缩略图；不是把全部原图放入 GPU。

接收时先确定顺序，再处理图像。只有纹理就绪并收到真实渲染确认后才开始计时：0–2 秒淡入，15 秒开始淡出，18 秒退出。参数可改。处理中、预加载、排队、当前照片都支持删除；照片历史与背景历史分开，删除会清除当前照片贡献、纹理和文件，迟到的处理任务不会恢复它。

手机上传：手机与电脑在同一个可互通的 Wi-Fi，点击“手机上传”选择真实网卡地址，扫码。换网络后重启服务以刷新地址。若有 VPN / 虚拟网卡，选择 WLAN 地址；防火墙或 Wi-Fi 客户端隔离仍可能阻止访问，应用不自动修改系统防火墙。

观众页面只有上传及自己的回执。管理页面和图片媒体需要管理员会话；手机管理密钥在本机“输出”页查看。不要将该密钥分享给观众。可在“现场 → 照片显影设置”启用“新照片先审核”。这是局域网工具，请勿直接转发端口到公网。

## 录制对比

“输出 → 录制三版对比”会用相同的原创测试音频和种子，顺序录制混沌、风暴、弦流各 30 秒的 WebM，含音轨，保存到浏览器下载。录制时照片队列暂停；完成后恢复配置与暂停状态。允许本站连续下载三个文件。录制有编码开销，不能用录制期间的帧率代表纯演出帧率。

录制仅捕获生成的 canvas 和本地测试音轨，不记录共享桌面视频。

## 可选 VirtualDJ 数据桥

桥默认关闭，不自动修改 VDJ 配置。当前本机尚未确认真实 OSC / OS2L 数据接入，界面保持“VDJ 尚未连接”。

如已在 VDJ 配置且授权 OSC，可在启动前设置对应端口：

```powershell
$env:VDJ_OSC_PORT=9000
$env:VDJ_OSC_LISTEN=9001
$env:VDJ_DECK=1
npm start
```

服务只向本机订阅 `get_bpm`、`get_beatpos`、`get_beat_num`，不发送播放 / 停止操作。`VDJ_OSC_LISTEN` 应匹配 VDJ 的返回端口。OSC 选项及授权以 [VDJ 官方说明](https://virtualdj.com/manuals/virtualdj/appendix/optionslist.html) 为准。

OS2L 为另一条可选路径：设置 `VDJ_OS2L_PORT` 后监听本机 TCP；没有实现自动服务发现，需自行配置 VDJ 直连地址。两条桥择一启用。字段未知时为 null，失联 3 秒退出同步。协议解析测试通过不等于真实 VDJ 联调成功。
